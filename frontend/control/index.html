            部署

            還沒有可部署的站點

            部署對象是已加入多站集群的站點。新伺服器請先在中控登記 SSH 連線、核對主機指紋並連線檢測，再建立首次安裝計畫。

            1. 添加 SSH 伺服器：遠端主機，或與中控同一台（選「中控本機」）。
            2. 核對主機指紋：確認連到的是正確的伺服器。
            3. 連線檢測：Linux、Python 3.10+、Docker Compose v2、root 與 Docker 權限。
            4. 首次安裝：建立計畫並確認，安裝業務後端、PostgreSQL、Redis，使用既有 RustFS。
            5. 加入多站集群：安裝後是獨立業務站；加入需另外配置資料面與加入協議。

                                2 · 私網與入口

                                    添加 SSH 伺服器

                                    位置

                                    「中控本機」指運行中控服務的那台伺服器，並非你正在開啟網頁的這台電腦。

                                    • 那台伺服器仍需要執行 SSH 服務，並提供有效的 SSH 帳號與憑據。
                                    • 若中控在容器內，127.0.0.1 指的是該容器；請改選「遠端伺服器」並填能到達宿主機的位址。
                                    • 業務站使用獨立的安裝目錄與 HTTP 埠；中控只安裝與更新業務站，不會更新或覆蓋中控自身。
                                    執行權限

                                    憑據來源

                                    認證方式

                                    憑據只送出一次，中控加密保存，之後不會顯示或回傳，也不會存在瀏覽器。

                                    主機指紋

                                    在伺服器上可用 ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub 查看（其他類型改用對應檔名）。

                                      首次安裝計畫

                                      只監聽目標主機 127.0.0.1，供目標主機 Nginx 轉發；不能使用 18080、18081。

                                      站點角色

                                        接入集群

                                        首次接入只支援空集群：把「中控本機」的已安裝校內業務站設為首個權威站。中控會改接該站的資料庫並短暫重啟（約 30–120 秒）；兩邊原有資料與帳號都保留。這是單站集群，跨站同步尚未啟用，新增其他成員會被拒絕。

                                        接入集群任務

                                        接入任務與安裝任務分開。完整列表見「任務歷史」；也可在此依 UUID 查詢，重新登入後會自動查回最近的接入任務。任務只有總體狀態與階段。

                                        安裝／更新任務

                                        完整列表見「任務歷史」；也可在此依任務或計畫 UUID 查詢。任務只有總體狀態。

                                        任務歷史

                                        安裝、更新、恢復、接入與集群部署任務。列表只讀；核對在任務詳情中確認後進行。
